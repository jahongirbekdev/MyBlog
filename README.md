# MyBlog

MyBlog — веб-платформа для ведения и управления блогом. Проект состоит из backend API, пользовательского интерфейса и административной панели.

## Структура проекта

### 1. MyBlog API

Backend-часть приложения, отвечающая за бизнес-логику, обработку запросов и взаимодействие с базой данных.

### 2. MyBlog Frontend

Пользовательский интерфейс для взаимодействия с платформой и просмотра контента.

### 3. MyBlog Admin Frontend

Административная панель для управления контентом и другими данными проекта.

## Технологии

* **Backend:** PHP, Symfony, API Platform
* **Frontend:** JavaScript, Vue.js
* **База данных:** MySQL
* **Инструменты:** Docker, Git
